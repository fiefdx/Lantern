# v1.6 — the emoji table in the window

Five minutes. This exists because Win + . could not be relied on; nothing else about emoji changed.

| # | step | expected |
| --- | --- | --- |
| 1 | Open a room and press **Emoji** on the strip above the message box (v1.7; it used to be beside it). | A small window opens just above/below the button: a **table** of 48 tiles in 8 columns, each a **colourful** face. It does not block the room - you can still scroll the transcript while it is open. |
| 2 | Click **😀**, then click **😃**. | Both appear in the message box, **in that order**, side by side: `😀😃`. (The second one replacing the first is the bug that was found and fixed; check it twice if you doubt it.) |
| 3 | Type `chuc mung`, put the caret between the two words, click a face. | The face goes in **at the caret**: `chuc😀mung`, caret after the face. |
| 4 | Highlight a word and click a face. | The face replaces the highlight - that is what an insertion is. |
| 5 | Look for **👨‍👩‍👧** and **🇻🇳** (bottom row). | Each is **one tile**, and lands in the message as one character. Send one and it is one picture in the transcript. |
| 6 | Fill the box to 500 characters (paste a long line), then click a tile. | Nothing is added and the status bar says: *"a message is 500 characters, and this one would be 501"*. Nothing you had typed is lost or trimmed. |
| 7 | Open the table, press **Escape** (or **Close**). | The table goes away, the message box is exactly as it was, no empty message is sent, and the caret is where you left it. |
| 8 | Send a face. | It appears in the transcript **in colour** (v1.5), and the other machine sees it too. |
| 9 | Share a picture and a file, then right-click the file's page, then click Emoji. | Saving still works with a table of pictures in the window: the picker does not disturb the file handling from v1.3.1. |
| 10 | Join from a second machine, send faces both ways. | Each side draws its own faces from its own font, in colour, including any face the *other* side chose from this table. |

If the tiles are empty squares, the colour renderer is unavailable on that machine (no `seguiemj.ttf`, or
`libSkiaSharp.dll` not next to `Lantern.exe`): the tiles then show the characters themselves instead of a picture,
and sending still works.
