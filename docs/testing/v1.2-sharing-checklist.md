# v1.2 — sharing in both directions

Saving what was shared, and watching a transfer go. Steps 1–6 need two machines over Bluetooth; 7–9 can be done
on one machine with two windows if you must, but the timings are only real over a radio.

Write down what you actually saw, including the sizes and how long things took. "It worked" cannot be read next
month.

| # | Do this | Expect | Seen? |
|---|---|---|---|
| 1 | Host: Share a photo (a few MB) | The bar moves at once and the line reads `sending <name> - <size> - <n> s`, the seconds counting up. **No Stop button** — half of one frame cannot be stopped | |
| 2 | While it is still going, look at the other laptop | Nothing half-arrived is shown; the photo appears when the last of it lands, and the file-ready sound plays once | |
| 3 | Right-click the photo's entry on the receiving machine → Save picture to… → pick a folder | The photo is written there under its own name. Open it: it is the photo, not the thumbnail | |
| 4 | Do step 3 again into the **same** folder | A second file with a number on the end (`sunset (2).png`). The first one is unchanged — open it and check | |
| 5 | Right-click a **file's** entry (one that already arrived and was answered) → Save file to… | It is written again from Lantern's area, and the bar says so. The bytes match what was sent | |
| 6 | Right-click an ordinary sentence; right-click a file **you** sent | Neither shows a menu. The file you sent is already on this machine | |
| 7 | Share a big file (~50 MB) both ways | The line reads `receiving <name> 34% - 17 MB of 50 MB` (or `sending`). It changes about four times a second and the number only goes up | |
| 8 | Ask for the same received file twice from the transcript | The second request says `… is already saved at <where>`, and only one copy is in the folder | |
| 9 | Share a photo and a file at the same time | The file owns the bar (it has a real percentage); the photo's line returns when the bar is free. Nothing sticks at 34% after it has finished | |
| 10 | Save a shared thing into a folder you then delete, then right-click the entry and save again | It writes where you say now. It does not claim to have saved something it did not | |
