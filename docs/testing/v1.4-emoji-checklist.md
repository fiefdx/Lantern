# v1.4 — emoji, accents, and what a character is

One machine is enough for steps 1–6; steps 7–9 want two over Bluetooth.

Say what you actually see, in words. Whether the faces came out in colour or in outline is exactly the sort of
thing "it works" hides, and it is the one thing about emoji this project cannot decide from a test.

| # | Do this | Expect | Seen? |
|---|---|---|---|
| 1 | In the message box press **Win + .** (or **Win + ;**) | Windows puts its emoji picker at the caret. Pick one and it lands in the box like any other character | |
| 2 | Send a face and look at it in the transcript | It is **drawn** — not a gap, and not an empty box. Colour or outline is Windows' choice, not Lantern's: write down which you got | |
| 3 | Send `cà phê 😀🎉` | It arrives exactly as typed. Accent marks and emoji are both only text here, and neither is rewritten on the way | |
| 4 | Paste 251 faces and press Send | It is sent. That used to be refused as a 502-character message. 500 faces are the most there is; the 501st is refused and the bar says 500, which is a number you can check | |
| 5 | Send a joined family (👨‍👩‍👧) and a flag (🇻🇳) | Each counts as **one** character and is drawn as one picture, because that is what you see | |
| 6 | On the second machine, set the nickname to sixteen emoji | Accepted — it used to take eight. It shows in the member list and in every headline in the room | |
| 7 | Share a file whose name has an emoji in it (`😀.png`) to the other machine | The entry reads with the same name on both, and its page says **PNG** | |
| 8 | Over Bluetooth, send a 500-face message from the client | It arrives whole. 500 faces are 1000 UTF-16 units and 2000 UTF-8 bytes, and the wire counts bytes | |
| 9 | Host: Edit → New room, name it with emoji, then join it from the other machine | Both windows list the same room with the same name | |

## What this sheet cannot decide, and what the tests do

Whether Windows paints an emoji in colour inside the transcript is a screen and an eye.

What the suite guarantees is narrower, and worth saying plainly:

* the characters survive the box, the room, the framing and the redraw;
* a message is measured in the characters somebody counts, so the refusal says a number they can check;
* the cell where an emoji sits has ink in it, **and** is not the same picture as the box Windows draws for a
  character it has no glyph for — because "something was drawn" is equally true of a row of empty boxes.
