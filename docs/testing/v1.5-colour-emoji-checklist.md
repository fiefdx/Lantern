# v1.5 colour emoji — what to look at

Five minutes on one machine, then four more on two machines and a link.

The code guarantees that the face put in the line came from Windows' own emoji font and that it has colour in it.
What it cannot guarantee is that the result is the picture you wanted, at a size you can read, on both machines.

## On one machine (5 minutes)

Rebuild first, then **Win + .** — the Windows emoji picker. Do not paste emoji from anywhere else in these first
steps; the whole point is whether the face you chose is the face you get.

| # | step | expected |
| --- | --- | --- |
| 1 | Pick **😀**, send it. | In the transcript: a **coloured** face, about as tall as the words around it, on the same line as them. In the message box while you type it: still an **outline** glyph — that is expected, and is step 8. |
| 2 | Send a sentence with faces inside it: `chúc mừng bạn nhé 😀🎉😍❤` | Every face colourful, none overlapping, none clipped, the Vietnamese words unaffected. Watch that the line is not taller than its neighbours by an awkward amount. |
| 3 | Send **👨‍👩‍👧** (family) and **🇻🇳** (flag). | **One** picture each, not three people and not two halves of a flag. |
| 4 | Send a face three times in a row: `😀😀😀` | Three pictures, each the same size. Not one wide picture, not two overlapping. |
| 5 | Send `ế 🇻🇳 ế`, and a message that is only `cà phê`. | The letters stay letters. A word must never turn into pictures. |
| 6 | **Select all** in the transcript (Ctrl+A) and copy into Notepad. | The words arrive. The faces **do not** — a picture is not a character. This is the price of colour and it is written in the README; check it is the only thing missing. |
| 7 | Send a picture (Share → an image), then a file (Share → a .pdf), then a message with a face. | All three on screen: the thumbnail, the file's page icon, the colourful face. Right-click the page icon → the save menu still appears; double-click the thumbnail → the viewer still opens. |

## On the box you type into

| # | step | expected |
| --- | --- | --- |
| 8 | Look at the message box before sending. | Outline glyph. Deliberate: an edit control cannot hold a picture, so colour in the box means changing the control, which has not been decided. If this bothers you more than it bothers the writer, say so — it is the one remaining piece. |
| 9 | Send **500** faces (paste from the picker repeatedly, or copy a long run in). | Accepted as exactly 500 characters; the transcript takes 500 pictures without falling over. One more than 500 is refused with the usual message. |

## Over the link (two machines)

The emoji itself travels as text, unchanged — the colour is drawn by whichever machine is displaying it, from its
own font file. So the other machine has to be running v1.5 to show colour, and needs its own Segoe UI Emoji (any
normal Windows 10/11 has it).

| # | step | expected |
| --- | --- | --- |
| 10 | Host on A, join on B, send faces both ways. | Each side sees colourful faces, drawn by its own Windows. Same face shape on both, since both read the same font version — if the shapes differ, the two machines are on different Windows updates, and that is a Windows fact rather than a Lantern one. |
| 11 | On B, right-click a file that A sent. | Save menu appears (v1.3.1) — and the transcript now carries pictures in its text stream, so this is the check that file handling survived. |
| 12 | Send a message with faces and a **newline** in it, then switch rooms and come back. | The entry comes back the same: faces still pictures, still in the right place, and the file entries still show their pages. |

## If colour does not appear

`ColorEmoji.Available` is the switch: it is false when `C:\Windows\Fonts\seguiemj.ttf` is missing or Skia could not
open it, or when `libSkiaSharp.dll` did not get next to `Lantern.exe`. In that case Lantern writes the outline glyph
instead of losing your message, and everything else in this checklist still passes except the word "coloured".
