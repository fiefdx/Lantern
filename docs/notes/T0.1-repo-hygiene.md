# T0.1 — Git repo hygiene

**Done.** What is in place:

* Repo root is `Lantern/` with `master` as the only permanent branch. Renamed
  from `main` on 2026-10-17 (`git branch -m main master`), at the request of the
  person who works on the trunk: they wanted its name to be `master`. The rename
  is local, as a branch rename always is; there were no worktrees, no stashes and
  no other branches to move. The remote - `origin` is
  `git@github.com:fiefdx/Lantern` - was dealt with by the person who asked, and
  this copy now tracks `origin/master` (see CONTRIBUTING).
* `.gitignore` for .NET / Visual Studio output (`bin/`, `obj/`, `.vs/`,
  `.idea/`, NuGet packages, test results) plus Lantern's own runtime artefacts
  (`rooms.json`, `received/`).
* `CONTRIBUTING.md` records:
  * branch naming (`m<n>-t<n>.<n>-<slug>`), squash-merge PR flow, `master` stays green;
  * the group contract **Definition of Done** (no warnings, runs from `master`,
    tested by a non-author, usage note);
  * **one owner + one backup per module** (UI / Storage / Domain+Core / Transport);
  * commit-message convention `T<id> [area] summary`.
* `docs/` holds the proposal, this breakdown, the UML sources + rendered PNG/SVG,
  and the wireframe PNGs so the repo is self-contained.
* `docs/notes/` holds the "how to use" note for each finished task (contract rule 4).
